# Boilerplate SaaS Genérico

Bienvenido a tu nuevo boilerplate SaaS con Next.js, TailwindCSS, shadcn/ui, Supabase y Mailgun.

- **Next.js** (App Router)
- **TailwindCSS** + **shadcn/ui**
- **Supabase** (Auth + DB)
- **Mailgun** (Email)
- **Nextra** (Docs MDX)

## Estructura

- Autenticación con Supabase
- CRUD genérico ("Item")
- Invitaciones por email
- Roles básicos
- Documentación en MDX

Explora las secciones para ver ejemplos y cómo adaptar este boilerplate a tus necesidades.
