# Documentación técnica (MDX + Nextra)

Esta documentación está construida con [Nextra](https://nextra.site/) y archivos MDX en la carpeta `/docs`.

## Estructura sugerida
- `index.mdx`: Introducción
- `auth.mdx`: Autenticación
- `crud.mdx`: CRUD genérico
- `email.mdx`: Invitaciones por email
- `roles.mdx`: Roles y permisos

Puedes agregar más archivos MDX para ampliar la documentación de tu SaaS.
